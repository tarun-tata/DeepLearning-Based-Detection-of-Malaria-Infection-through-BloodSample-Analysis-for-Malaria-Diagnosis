# Deep Learning-Based Detection of Malaria Infection through Blood Sample Analysis for Malaria Diagnosis

## Project Overview

This project presents an AI-driven healthcare application for automated malaria infection detection using Deep Learning Convolutional Neural Networks (CNNs). The system analyzes microscopic blood sample images and classifies them into Parasitized and Uninfected categories with high accuracy and reduced human intervention.

The proposed system focuses on:
- Medical image analysis
- Artificial Intelligence in healthcare
- Deep learning-based disease diagnosis
- Automated blood sample classification

The project aims to support healthcare professionals by improving diagnostic efficiency, minimizing human error, and enabling early malaria detection.

## Methodology

### 1. Data Collection
Microscopic blood sample images are collected from publicly available medical datasets.

### 2. Image Preprocessing
The preprocessing stage includes:
- Image resizing
- Normalization
- Noise reduction
- Image enhancement

### 3. CNN Model Development
The Convolutional Neural Network is implemented using:
- Convolution Layers
- Pooling Layers
- Dense Layers
- SoftMax Classification

### 4. Model Training and Evaluation
The model is trained using labeled datasets and evaluated using:
- Accuracy metrics
- Loss analysis
- Confusion matrix
- Classification report

### 5. Prediction System
The trained model predicts whether the uploaded blood sample image is:
- Parasitized
- Uninfected
